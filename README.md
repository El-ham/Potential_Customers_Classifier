
# Overview

ExtraaLearn is an EdTech startup offering upskilling programs. The goal of this project is to build a machine learning model to predict lead conversion and optimize marketing strategies.

# Objectives

Predict lead conversion using ML models.

Identify key factors influencing conversion.

Provide actionable insights for marketing optimization.

# Dataset

Key Features: Age, Occupation, First Interaction, Profile Completion, Website Engagement, Last Activity, Marketing Channels.

Target Variable: Lead Conversion (0 = Not Converted, 1 = Converted).

# Data Processing & Analysis

✅ Handled missing values and encoded categorical variables.

✅ Performed exploratory data analysis (EDA) to uncover key patterns.

✅ Identified website engagement and referrals as top conversion drivers.

# Model Building & Results

🔹 Decision Tree Classifier: Tuned with GridSearchCV, achieving 87% accuracy.

🔹 Random Forest Classifier: Optimized with hyperparameter tuning, reaching 87% accuracy.

🔹 Key Features: Time spent on website, First interaction via website, Profile completion.

# Key Insights & Recommendations

📌 Boost Website Engagement: Improve content, add interactive elements.

📌 Leverage Referrals: Implement incentives for referrals.

📌 Target Students: They show the highest conversion rates.

📌 Encourage Profile Completion: Offer incentives for completing profiles.

📌 Optimize Digital Marketing: Prioritize high-performing channels over print media.

# Conclusion

This project successfully predicts lead conversion and provides actionable insights to optimize marketing efforts. Future steps include experimenting with advanced ML models and refining marketing strategies based on ongoing data analysis.

Technologies Used

🛠 Python, Pandas, Scikit-learn, Seaborn, Matplotlib.
